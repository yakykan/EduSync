# EduSync

Учебная мини-система: регистрация, вход, курсы, оценки (Python + SQLite).

## Руководство пользователя (Т7)
1. Установите Python 3.
2. Создайте базу и тестовых пользователей: `python app.py`
3. Резервная копия: `python backup.py`
4. Проверка восстановления: `python restore_check.py`
5. Автотесты: `python test_edusync.py`

Вход: логин `student1`, пароль `pass123`. После 5 неверных паролей учётная запись блокируется.
